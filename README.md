# Govorim-pravilno.ru

Website von Svetlana Konovalova (Logopädie).

## Entwicklung

```sh
npm install
npm run dev      # lokaler Entwicklungsserver
```

## Veröffentlichung

```sh
npm run build    # erzeugt den Ordner dist/
```

Der Ordner `dist/` enthält die fertige Website und wird auf den Server hochgeladen.
